# GTA 6 — Open-World Crime Game (make.fun gta6-01)

An original 3D open-world crime game built for the make.fun gta6-01 bounty: explore a sun-soaked city on foot and by car, steal cars, dodge the police, take on missions, and build your wanted level. All content is original — nothing from Rockstar Games or any other commercial game.

Built with Three.js (vendored as `*.min.js`), plain static files under `game/`, no build step.
